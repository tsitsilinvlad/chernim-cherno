# Inventory Intelligence — Stage 2

Это production-структура MVP v1 под твой внутренний продукт.

Что уже есть:
- Next.js 14 + TypeScript
- SQLite через Prisma (для простого старта)
- логин через NextAuth Credentials
- 2 роли: owner и employee
- серверный импорт Excel
- история загрузок в базе
- настройки порогов в базе
- сравнение текущей загрузки с предыдущей

## Быстрый запуск

1. Установи Node.js 20+
2. Распакуй проект
3. Скопируй `.env.example` в `.env`
4. Заполни логины и пароли
5. Запусти команды:

```bash
npm install
npx prisma generate
npx prisma db push
npm run dev
```

Открой `http://localhost:3000`

## Деплой на Vercel

1. Создай GitHub репозиторий и загрузи проект
2. Импортируй репозиторий в Vercel
3. Добавь переменные окружения из `.env.example`
4. Для простого демо можно использовать SQLite локально, но для нормального деплоя лучше сразу перейти на Postgres
